# Machine Learning & Data Science Internship Portfolio

A collection of end-to-end machine learning and data science pipelines built during my 4-week internship[cite: 3]. Each project focuses on clean data preprocessing, feature engineering, model evaluation, and reproducible code.

## Project Overview

| Task | Project Title | Core Techniques & Models | Key Focus |
| :--- | :--- | :--- | :--- |
| **Task 1** | [Multi-Class Benchmark Classification](./Task-01-Multi-Class-Classification) | Scikit-Learn Pipelines, StandardScaler, Logistic Regression / SVM | Data normalization & confusion matrix evaluation |
| **Task 2** | [Real Estate Housing Price Prediction](./Task-02-Housing-Price-Prediction) | Ridge & Lasso Regression, Feature Engineering | Continuous regression & residual error analysis |
| **Task 3** | [Predictive Customer Churn Classifier](./Task-03-Customer-Churn-Prediction) | Random Forest, XGBoost, SMOTE / Class Weights | Handling class imbalance & ROC-AUC optimization |
| **Task 4** | [NLP Sentiment Classification](./Task-04-NLP-Sentiment-Classification) | Text Preprocessing, TF-IDF Vectorization, Linear Classifiers | Textual corpus cleaning & review polarity prediction |
